LaTeX 与网页公式

LaTeX ↗ 是一种文档排版系统。通过文字命令描述内容与结构，可以统一处理数学公式、章节、交叉引用和参考文献，常用于论文、讲义与技术写作。

MathJax ↗ 与 KaTeX ↗ 则负责把数学标记渲染为网页中的公式。Aitopia 使用 KaTeX：上方编辑器输入的是 LaTeX 的数学语法，无需安装软件，也不必把公式保存成图片。网页公式引擎支持的命令范围与完整 LaTeX 文档不同。

在这里怎样输入？

上方编辑器直接写 \nabla f(\mathbf{x})，不加公式定界符；写文章或下方讨论时，用 $…$ 包围行内公式，用 $$…$$ 包围独立公式。完整论文的 \documentclass、\begin{document} 等文档命令，应在 LaTeX 文档编辑器中使用。

文字中的公式梯度为 $\nabla f(\mathbf{x})$。

几个常见的书写细节
  • 上下标超过一个字符时，用 {…} 分组，例如 x_{ij}；要显示大括号本身，用 \{ 和 \}。
  • 矩阵中用 & 分列、\\ 换行；aligned 中的 & 指定对齐位置。
  • 用 \sin、\log 或 \operatorname{…} 书写算子；用 \text{…} 嵌入文字。
  • 数学模式中的普通空格通常会被忽略。\,、\;、\quad 可以调整间距，\! 可缩小间距。
