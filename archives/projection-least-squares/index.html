最小二乘：把误差放到正交的方向

先找可到达的空间残差必须正交实现时选择分解投影之外的假设

线性方程组没有精确解时，我们仍能找到最接近的可实现结果。最小二乘的几何解释，比直接记住一串逆矩阵更有帮助。

先找可到达的空间

向量 XβX\betaXβ 只能落在 XXX 的列空间中。最小化 ∥y−Xβ∥22\|y-X\beta\|_2^2∥y−Xβ∥22​，相当于把观测向量投影到这个空间。

残差必须正交

对目标函数求导，得到正规方程：

X⊤(Xβ^−y)=0.X^\top(X\hat\beta-y)=0.X⊤(Xβ^​−y)=0.

这说明残差 r=y−Xβ^r=y-X\hat\betar=y−Xβ^​ 与每个特征列都正交。若列满秩，可以形式上写出 β^=(X⊤X)−1X⊤y\hat\beta=(X^\top X)^{-1}X^\top yβ^​=(X⊤X)−1X⊤y。然而推导中出现逆矩阵，不意味着代码里必须显式求逆。

实现时选择分解

形成 X⊤XX^\top XX⊤X 会把二范数条件数平方。对于接近线性相关的特征，QR 或 SVD 往往是更稳健的求解方式。

import numpy as np
coef, residuals, rank, singular = np.linalg.lstsq(X, y, rcond=None)
prediction = X @ coef

投影之外的假设

代数上的最小二乘解，并不自动等于统计上的可靠因果结论。误差结构、抽样方式和模型遗漏决定了我们能如何解释系数。加入一个特征可能降低训练残差，却不保证降低预测误差。

可以做一个小实验：把两列特征逐渐变得相似，观察系数大幅变化，而预测向量仍相对稳定。参数稳定与预测稳定，是两个不同的问题。

参考：NumPy 的 lstsq 文档。
